# Aresta Landing Page Builder

Use os documentos de análise de dados e manual de marca para construir a landingpage do aresta. 

Vou enviar aqui também as pastas com os 3 modelos que mais gostei de landing page, em especial o 3. Precisamos simplificar e unificar a landingpage do editor: https://arestaclimb.com/editor
